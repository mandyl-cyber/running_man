# 7 分钟阶段汇报 PPT 设计（2026-11-16）

## 讲述目标与口径

面向有理工背景、但未参与项目的听众。核心问题是：**从人类动作到 G1 越障，哪些环节已得到闭环验证，哪个环节尚未完成？** 汇报重点是自己的阶段性证据，不是复述整篇论文。建议 7 页、严格 7:00；现有 `大创项目.pptx` 的链路图保留并精简为第 3 页，不再额外画一张重复的流程图。

必须区分三类陈述：**论文已实现**（PHP 的多技能实机跑酷）、**本项目已验证**（40 条低墙轨迹的 Teacher clean 评估）、**下一步目标**（可自主越障的 Student、多技能及跨仿真/实机）。所有成功率旁写清策略、数据、起点与评估条件。

## 逐页内容与讲稿

### 1｜题目与研究问题（0:00–0:20）

- **标题：**“面向复杂环境的人形机器人多技能感知控制与行为生成：阶段进展”。副标题可用“从动作数据库到低墙 Teacher，再到 Student 的自主控制瓶颈”。
- **画面：**一张 G1 越障图或视频封面；不要在封面放算法框图。
- **口播：**“我们希望让 G1 根据前方障碍自主选择并执行动作。目前已经把参考动作生成和低墙 Teacher 跟踪跑通，下一步的核心是让没有特权信息的 Student 也能独立完成。”

### 2｜论文目标与本项目范围（0:20–1:05）

- **标题即结论：**“PHP 展示多技能感知跑酷；我们的已验证范围仍是低墙任务。”
- 左侧使用 `parkour.pdf` 图 1 的**论文示例**（注明“Wu et al., PHP，论文结果”）；右侧用两行文字界定本项目：已完成 40 条低墙 motion–terrain 配对数据上的 Teacher clean 评估；Student、多技能、真实机器人部署尚未验收。
- 解释三个词即可：**reference** 是期望跟踪的逐帧动作，**motion–terrain pair** 是动作与障碍几何/位置绑定，**privileged observation** 是仿真中可直接取得、实机未必可用的状态。
- **口播：**“论文最终是在真实 G1 上实现自主连续跑酷。我们的阶段目标不是声称达到论文的全部能力，而是逐环验证这一训练路线，当前重点是低墙。”
- **不要说：**“已复现 PHP 实机跑酷”或“40 条就是论文所有技能”。

### 3｜系统链路与分工（1:05–1:50）

- **画面：**沿用 `大创项目.pptx` 唯一一页的横向链路，重新排版成六个简短框：人类动作 → OmniRetarget 重定向 → Motion Matching → Teacher RL → Student 蒸馏 → Sim-to-Sim/Real。用颜色区分“已验证”“进行中”“待验证”，每框至多一行字。
- **口播：**“重定向把人类动作映射到 G1；Motion Matching 把站立、接近、越障、离开接成参考轨迹；Teacher 利用特权信息学习物理跟踪；Student 从自身状态和深度感知中学习自主控制。最后才是跨仿真与实机。”
- **改旧图：**把图中 Teacher 的旧数字 **94.55%** 改为最新、注明条件的 **95.9%**；把“Student 仅完成接入准备”改成“已训练并完成无接管评估，但未通过自主验收”。Sim-to-Sim/Real 保持“计划/待验证”，不要画成已完成。

### 4｜Motion Matching：数据与质量（1:50–2:55）

- **标题即结论：**“建成检索库和动作—地形生成链路，但新增轨迹必须经物理准入。”
- **画面：**左边一个简单的 `站立 → 接近 → 越障 → 离开` 时间条；右边三个数字：**152 条原始片段、304 条含镜像条目、107,492 帧**。下方一张实际生成轨迹与障碍物一起显示的图，圈出 skill 入口与接触点。
- **讲明方法：**Motion Matching 按未来位移/朝向、脚的位置速度和根部速度检索相近帧，再平滑拼接；障碍物位姿必须跟技能动作一起变换。镜像条目不是 152 条新的独立数据。
- **讲明局限：**已做轨迹边界、连续性和配对检查，但**离线平滑不保证接触正确或 Teacher 可跟踪**。已有对照显示，有些新 MM 候选从技能段起跑可完成，从完整接近段起跑会失败；这支持“接近分布/技能入口状态需要再验证”，不证明所有失败都由数据造成。
- **口播收束：**“下一步扩库不只加数量：要加入 LAFAN 之外的素材、受控的变速/变向以及 step/climb，并逐组检查实际速度、接触、地形配对和完整物理回放。”

### 5｜Teacher：最强正结果（2:55–4:15）

- **标题即结论：**“在已测的低墙 clean 条件下，Teacher 能稳定完成完整轨迹。”
- **画面：**大字 **3837/4000 = 95.9%**；旁边写完整口径：**官方 PHP/Holosoma 训练的 Teacher、40 条 motion × 每条 100 次、clean、固定 frame 0、full-clip、报告 complete=true**。下面可放逐 clip 成功率分布或 2–3 秒同一 checkpoint 的代表性视频；如视频不是这次 `model_19999.pt` 的输出，必须另标“演示样例”，不可拿来证明 95.9%。
- **简述方法：**PPO + 全身运动模仿；Teacher 训练时可读参考动作、全局状态和地形扫描。它证明“这些配对参考可被强观测策略物理跟踪”，不是部署性能证明。
- **与旧实验的关系：**本地 E6/E7 的单/五轨迹正结果证明了早期工程链路，但**不是**上述 40 条官方 Teacher 的同一 checkpoint，不能把两者混成一组实验。
- **口播：**“这是本项目最可信的正结果：评估从动作第 0 帧开始，走完整条，不是训练日志里从中间采样的 adaptive success。95.9% 只代表已测 clean 数据，不代表随机扰动、新技能或实机也达到这个数字。”

### 6｜Student：尚未突破的瓶颈（4:15–5:55）

- **标题即结论：**“Teacher 能跟踪，Student 仍不能稳定自主越障。”
- **画面：**两栏比较，避免误导性并列柱状图：Teacher **3837/4000，clean、特权观测**；Student 当前已测最佳 `model_30098.pt` **39/480 = 8.1%，clean、40 条 × 3 次 × seeds 43–46、无 Teacher 接管**。在图下注明：两者观测和评估样本不同，**不是严格同条件的模型优劣 A/B**。
- **解释机制：**Student 使用深度与本体状态，训练已包含 **DAgger + PPO**，并非“忘了蒸馏”。DAgger 是在 Student 自己访问的状态上请 Teacher 给动作标签。但 Student 早期小偏差在障碍接触阶段被放大；当前路由会把部分大偏差状态标为无效，随后不再提供对应 DAgger 标签。250 帧以后的一项结构测试中，有效标签约 **2641/8163（32.4%）**。
- **区分证据与假设：**早期漂移、标签屏蔽和低成功率是观测事实；“哪一个是首要根因”尚未由严格受控的训练 A/B 确定。Teacher 中途接管提高成功率，只能说明辅助恢复有潜力，**不能算 Student 自主成功**。
- **口播：**“所以问题不是训练完全没跑，也不是单纯再调一个 PPO 超参数。现在需要先判断偏离后的状态是否真的可由 Teacher 救回，再决定哪些 Teacher 动作可以作为可靠监督。”

### 7｜下一阶段实验与结论（5:55–7:00）

- **标题即结论：**“从‘链路打通’进入‘自主能力验收’。”
- **画面：**三步门槛，不再重复第 3 页流程：
  1. **恢复监督实验：**保存 Student 首次偏离与标签失效附近的完整状态；从同一状态测试 Teacher 能否救回，只有验证可恢复的分支进入训练候选。
  2. **严格 A/B：**同一起点 checkpoint、相同训练预算与 seed，比较原方案和“加入可恢复状态监督”；先保证原成功 clip 不明显回退，再看 Student **无接管 full-clip** 是否超过当前 **39/480**。
  3. **扩展与迁移：**按速度/转向/step/climb 扩库；新增数据先通过接触、配对及物理跟踪门槛，再做 Teacher 逐技能评估；Student 通过后再推进 MuJoCo sim-to-sim 与真实 G1 的安全测试。
- **结尾原句可直接读：**“我们已经证明动作生成到低墙 Teacher 的链路有效；当前真正未解决的是有限观测 Student 在接触过渡中的自主协调与偏离恢复。后续将以完整轨迹、无接管、多 seed 的结果决定是否继续推进。”

## 参考文献如何使用

- **主论文：**`parkour.pdf`《Perceptive Humanoid Parkour》。用于第 2 页研究目标、第 3 页方法链路，以及第 6 页解释为何论文结合 DAgger 与 PPO。论文自己指出纯 DAgger 难覆盖动态技能，且 Teacher 与 Student 的信息条件不同。
- **技术手册：**`whole_body_tracking_cp.pdf`《RL Motion Tracking Implementation Manual》。可辅助解释参考轨迹、PPO、adaptive sampling 和验收，但它是实现手册，**不是本项目结果，也不能替代主论文证据**。
- **相关工作：**`light-loco-parkour.pdf`《Light-Loco-Parkour》。其参考—障碍物配对、动态可行性、过渡训练与深度策略记忆设计，可作为答疑/备份页的对照方向；使用了不同机器人、训练流程和评估场景，**不与本项目成功率直接比较**。
- **不放主讲：**`2604.03128v2.pdf`《Self-Distilled RLVR》研究的是大语言模型的 token 级自蒸馏与可验证奖励。它与“特权信息可能造成蒸馏信息差”只有概念关联，不能作为本项目机器人 Student 失败原因的直接证据；7 分钟汇报无需提及。
