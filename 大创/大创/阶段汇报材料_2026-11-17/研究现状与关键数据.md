# 人形机器人多技能感知控制项目：研究现状与关键数据

**资料截点：2026-11-17。** 本文用于阶段汇报；数值来自本文件夹收录的原始评估报告及项目交接文档，不把论文结果、旧版演示和本项目结果混为一谈。

## 1. 当前研究处于哪一步

项目以 PHP（Perceptive Humanoid Parkour）为主要复现参照，目标是让 Unitree G1 利用自身状态和深度感知，在复杂地形中自主选择并执行越障技能。研究链路是：人类动作重定向 → Motion Matching 合成动作—地形配对参考 → 特权观测 Teacher 学习物理跟踪 → 低特权观测 Student 蒸馏与强化学习 → 跨仿真、实机验证。

**目前完成的是链路前半段和 Student 训练/评估基础设施，不是最终多技能自主跑酷。** 本地已建立 G1 动作检索库；官方 PHP/Holosoma 路线训练的低墙 Teacher 在严格 clean 评估中取得强结果；Student 已按 DAgger+PPO 训练并能进行逐轨迹、无接管评估，但自主成功率仍低。Sim-to-Sim、Sim-to-Real 尚未形成可报告的验收结果。

## 3. 目前最重要的技术认识

1. **数据关：**Motion Matching 能把站立、接近、越障和离开拼成连续参考，并保存障碍物位姿；但运动学上平滑，不等于脚/手接触正确或策略可物理跟踪。扩库须按素材来源、实际速度/转向、接触顺序与障碍几何分层，新增/变形轨迹先做独立准入。
2. **Teacher 关：**训练日志中从中途帧采样的 `adaptive_success` 曾掩盖完整轨迹失败。现在的可信口径是逐 motion、clean、固定 frame 0、完整轨迹、报告完成度和失败原因。总体 95.9% 是强正结果，同时保留逐轨迹短板（最低 70%）。
3. **Student 关：**当前 Student **已使用 DAgger+PPO**，并非只用 PPO。现有记录支持一条待验证的问题链：早期动作/状态偏差在接触过渡被放大；部分大偏差状态被 Teacher 路由标为失效，DAgger 标签随之屏蔽；后续恢复监督减少。结构测试中，250 帧后的有效标签为 **2641/8163（32.4%）**。这不是“唯一根因已证实”；Teacher 能否从这些偏离状态恢复，仍需受控实验。

## 4. 下一阶段：按验收门槛推进

1. **先做 Student 恢复监督验证。** 在自主 rollout 中保存首次持续偏差和标签失效附近的完整状态；让 Teacher 从同一状态短暂接管并交回 Student，区分“可恢复”与“不可恢复”。不得把零动作或未验证的 Teacher 标签直接加入训练。
2. **再做单变量训练 A/B。** 相同起点 checkpoint、数据预算和 seed，只改变是否加入经验证的恢复状态监督。先检查原成功 clip 不明显回退，再用 40 clips × 3 episodes × seeds 43–46、clean、frame-0、无接管 full-clip 测试是否超过 **39/480**。辅助接管成功率只作机制指标。
3. **并行扩展参考分布。** 从 LAFAN 之外补充许可清晰的动作素材，并对现有 locomotion 做受控变速/变向；增加 step/climb 技能。每组先过关节/速度连续性、接触、motion–terrain 配对、物理 replay 与逐 clip Teacher 评估，再扩大训练集。
4. **后续才做迁移。** 新技能 Teacher 与 Student 均通过对应验收后，再在 MuJoCo 进行 sim-to-sim，对齐深度、关节控制、频率和终止条件；真实 G1 从低风险动作及安全停机验证开始。当前不能宣称这些阶段已完成。

## 5. 本文件夹怎么用

- [7 分钟 PPT 设计](slides/7分钟阶段汇报PPT设计.md)：逐页时间、画面、讲稿和措辞边界。
- `evidence/`：可复核的原始 JSON 和分段诊断。若重新训练或评估，**新结果不能覆盖这里的历史证据**；要另建带日期的文件夹。
- `media/`：旧版 E7 的攀爬/新增 MM 对照视频及分段图，适合解释“完整接近失败、技能段可行”。`mm_0003` 只是候选编号，**不是** `original_0003` 的配对变形；这些视频也**不是**官方 `model_19999.pt` 的 40 条评估录像，不能拿来证明上表 Teacher 95.9%。
- `slides/`：原链路 PPT 的副本仅供改稿；其中 **94.55%** 和“Student 仅完成接入准备”是旧表述，正式展示前必须按本文件更新。
- 原论文和参考文献仍放在上一级目录：[PHP 主论文](../parkour.pdf)、[RL 跟踪实现手册](../whole_body_tracking_cp.pdf)、[Light-Loco-Parkour](../light-loco-parkour.pdf)。`Self-Distilled RLVR` 是语言模型研究，不作为机器人 Student 失败的直接依据。

在本文件夹内可用以下命令复核两个核心分子/分母（需要 `jq`）：

```bash
jq '{complete, contract, successes:([.motions[].successes]|add), episodes:([.motions[].episodes]|add)}' evidence/teacher_clean_seed42.json
jq -s '{complete:([.[].complete]|all), intervention:[.[].intervention.mode]|unique, successes:([.[].motions[].successes]|add), episodes:([.[].motions[].episodes]|add)}' evidence/student_clean_seed4{3,4,5,6}.json
```

**一句话结论：**低墙 Teacher 已在明确的 clean、完整轨迹条件下取得可复核的强结果；当前主要瓶颈是 Student 的自主闭环控制与偏离恢复，而不是“训练链路尚未跑通”。
